3 Labāka klavieru skaņa · FreePats

Aizvieto vienkāršās klavieru skaņas ar FreePats Kawai Upright Piano (stereo WAV). Tā ir pianīna skaņa, nevis koncertflīģelis. Bezmaksas CC0 licence.

⬇ Mazā SFZ/WAV banka · 4,3 MiB⬇ Pilnā SFZ/WAV banka · 69 MiB

Ar interneta pieslēgumu lejupielādē banku un atarhivē .7z failu. Pēc tam izvēlies visu mapi kopā ar .sfz un samples/*.wav. Pēc importēšanas spēlē arī bez interneta.

Pašlaik tiek izmantotas iebūvētās klavieru skaņas.

Neviens skaņas fails netiek nosūtīts uz serveri. PWA versijā paraugi var tikt saglabāti šīs ierīces pārlūka krātuvē; portatīvajā HTML versijā faili pēc atkārtotas atvēršanas var būt jāimportē no jauna.

Instalēšana pa ierīcēm

Windows 11

Atver šo lapu Edge vai Chrome un izvēlies Install app. Nav jāpalaiž neparakstīts EXE.

Mac

Chrome → Install app. MIDI tastatūrai izmanto Chrome vai Edge, nevis Safari.

Android

Chrome → izvēlne ⋮ → Install app. USB MIDI atbalsts atkarīgs no tālruņa, pārlūka un OTG.

Apple iPad

Safari → Share → Add to Home Screen. MIDI failu atskaņošana strādā, bet USB MIDI klavieres Safari neatbalsta.

Pirmajā reizē atver lapu ar internetu, sagaidi norādi par saglabāšanu bezsaistē un pēc tam pārbaudi lidmašīnas režīmā. Skaņai nepieciešams pieskāriens pogai “Ieslēgt skaņu”.
