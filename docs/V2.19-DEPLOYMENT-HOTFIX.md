# v2.19 deployment hotfix

- Keeps `renderSources()` in the application bundle.
- Bumps all browser assets to `?v=39` and the service-worker cache to `music63-v219`.
- Registers `service-worker.js?v=39` instead of the old v30 registration URL.
- Guards user/login UI updates so a removed DOM node cannot crash a promise handler.
- Upgrade ZIP is intentionally packaged with files at ZIP root so extracting it in the live Music 63 document root overwrites the real live files instead of creating a nested `music-app-master/` directory.
