# Music 63 v2.4 - local-only handwriting scanner

The handwriting photo importer no longer asks for, tests, or depends on an AI/API connection.

Workflow:
1. Load handwriting photo.
2. Prepare / enhance image.
3. Scan handwriting -> notes.
4. Review the draft.
5. Replace, append, or create a new imported part.

The scan runs in the browser with `assets/handwriting-local.js`. No OpenAI request is made by the handwriting scan button.

Current local scanner scope: one handwritten treble-clef melody line. Chord letters and freehand text are not automatically recognized and can be added manually after import.
