# Music 63 v2.6 - local handwriting proofread

This update keeps handwriting recognition fully local and free. No API key is required.

## Changes

- Handwriting scan depth and rhythm grid are now separate controls.
- Barline detection now follows slightly slanted hand-drawn bar strokes across the whole staff, instead of mistaking note stems for barlines.
- Eighth-note timing keeps the final half-beat of a 4/4 bar instead of collapsing late notes onto beat 4.
- Default handwriting rhythm grid is 1/8 note; 1/16 and 1/4 are available when needed.
- Written key can be selected before scanning so key-signature accidentals are mapped correctly.
- Scanner keeps source x/y positions for every detected note.
- After scanning, green numbered markers appear directly over the prepared photograph.
- When a page contains several staff systems, each system can be turned on/off before import. This is useful when one row is vocal and another is clarinet/piano. Selected systems are compacted into consecutive bars.
- Remove mode deletes false detections by clicking their marker.
- Add mode inserts a missing note by clicking the correct staff position; pitch, bar and beat are calculated locally from the detected staff geometry.
- The imported result remains fully editable in the normal score editor.
- No AI or server image API is used for handwriting recognition.
