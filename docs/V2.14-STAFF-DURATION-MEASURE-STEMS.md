# Music 63 v2.14

This update focuses on notation correctness and handwriting correction.

- MIDI Write mode measures how long a key is held and maps it to a musical duration.
- Delete bar removes the selected measure from the full score and shifts later notes/chords left.
- Handwriting recognition refines blue staff-line geometry per local x-position and uses local line spacing for notehead snapping.
- Selected notes can be moved by line/space and re-applied to the current key signature, so F major maps the B staff position to B-flat.
- Down-stem eighth-note flags curve in the correct direction.
- Normal one-voice notation uses automatic stem direction (high notes down, low notes up). Voice 1/Voice 2 fixed stem directions are used only when multiple voices share a bar.
