# Handwritten score conversion - Music 63 v2.2

1. Open **Music Editor** and choose the target instrument/part.
2. Under **Handwritten import**, choose **Load handwriting photo**.
3. Music 63 automatically prepares a high-contrast image. You can rotate the photo and press **Prepare image** again if needed.
4. Press **Test image AI** once if conversion previously failed. This checks the saved API key/model with image input, not only text.
5. Choose **Melody + chord symbols** for pages like the example handwritten clarinet melody. Choose **Melody only** to ignore chord letters, or **All visible notes & rests** for fuller notation.
6. Keep **High accuracy** for difficult handwriting. Music 63 sends the original page, an enhanced page, and overlapping zoom strips as views of the same page.
7. Press **Convert to notes**. A draft appears with symbol count, confidence, warnings and detected notes.
8. Apply with **Replace current part**, **Add to current part**, or **Create new imported part**.
9. Correct any uncertain notes using the normal note inspector, red X delete, Passage correction, timing snap and beam controls.

## If it still fails

- Use **Test image AI**. If this fails, fix the API connection in Settings first.
- If the test passes but the score returns no notes, rotate the page so the staves are horizontal, press **Prepare image**, and retry High accuracy.
- The app reports PHP `post_max_size`, upload limits, model errors and timeouts directly in the handwriting panel.
- A close, sharp photo with the page filling most of the frame gives the best result.

The source image is sent server-side to the configured OpenAI Responses API only when you press Convert. The API key remains server-side.
