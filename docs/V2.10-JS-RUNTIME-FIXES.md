# Music 63 v2.10 — JavaScript runtime fixes

This maintenance update fixes editor-breaking JavaScript regressions introduced in the previous update.

## Fixed
- Restored the shared `toast()` notification helper used throughout the app.
- Restored editor undo/redo/checkpoint helpers.
- Restored local handwriting review helpers used by the note editor.
- Restored Audio → Notes helpers including `audioTargetPart()`, written-pitch conversion, chord application, source labels and YouTube preview URL generation.
- Service worker now ignores non-HTTP(S) and cross-origin requests, so browser-extension URLs such as `chrome-extension://...` are never written to Cache Storage.
- Cache writes are guarded so an unsupported request cannot break page requests.
- Static asset and service-worker cache versions were bumped to force browsers to load the corrected scripts.

## About the install-banner console message
Chrome may log `beforeinstallpromptevent.preventDefault()` while Music 63 stores the PWA install event for its own **Install app** button. This is informational and is not a runtime failure.

## If an old service worker is still active
Open `cache-reset.html` once. It unregisters old Music 63 service workers, deletes only caches whose names start with `music63-`, and then reloads the app. It does not delete songs, users, uploads or server settings.
