# Music 63 v2.7 - handwriting accuracy update

The handwriting scanner remains fully local in the browser and does not use an AI API key.

## Automatic changes

- Filled noteheads no longer inherit long durations just because the next detected note is far away. They default to quarter notes and shorten when the next onset is closer.
- Open noteheads are treated separately and default to half notes.
- Small repeat-sign dots beside strong barlines are filtered from melody-note candidates.
- Detected bar boundaries are drawn over the prepared photo for visual checking.

## Proofread workflow

After scanning, click any green numbered note marker. The draft shows controls to move the pitch up/down by one staff position, move timing left/right by the selected timing grid, shorten/lengthen the note, or remove it.

If the photo contains several musical parts, use the staff-system buttons before importing. The button labels show the note count in each detected system. Turn off systems belonging to another voice or instrument.

The scanner still does not reliably decode handwritten chord letters or every handwritten rest shape. Those should be corrected in the normal score editor when needed.
