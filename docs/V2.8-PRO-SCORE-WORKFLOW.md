# Music 63 v2.8 professional score workflow

This update moves the editor closer to a traditional notation application workflow: score setup is explicit, handwriting import preserves staff geometry, selected notes can be moved diatonically by staff step, keyboard instruments use grand staff, chord symbols can feed accompaniment, and ensemble templates create multi-instrument scores.

The local handwriting setup detector is intentionally conservative. If a photographed key or meter is unclear, choose it explicitly in the handwriting panel before importing. No API key is required.
