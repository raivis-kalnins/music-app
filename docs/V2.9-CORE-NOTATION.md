# Music 63 v2.9 — core notation workflow

This update adds a practical baseline for professional-style score work without depending on an AI API key.

- Local Smart Composer with multi-instrument roles
- Two voice layers with opposing stem directions
- Basic ties and slurs
- Staccato, accent, tenuto and marcato
- pp / p / mp / mf / f / ff dynamics
- Triplet / quintuplet markings and triplet input durations
- Drum Kit percussion staff with X noteheads for cymbal/hi-hat family notes
- Lyrics alignment helper
- Compact / standard / spacious engraving presets
- Concert-pitch display for transposing instruments
- MusicXML export/import for key, meter, voices, ties, slurs, articulations, tuplets, lyrics and grand staff
- Audio → Notes UI redesigned for readability
- Latvian translations expanded; runtime translation no longer calls an AI service
- Normal composition/settings no longer ask for an OpenAI API key

## Baseline professional notation

This release adds a practical first-pass implementation of the notation features expected in a full score editor: two voice layers, ties and slurs, articulations, dynamics, triplets/quintuplet metadata, a percussion staff, lyrics syllables, compact/standard/spacious engraving, written/concert-pitch viewing, MusicXML round-trip support, and deeper local handwriting OMR.

The Smart Composer and handwriting scanner run locally in the browser and do not require an AI API key. Multi-instrument composition now produces role-aware accompaniment/harmony/bass/drum parts instead of duplicating the melody into every selected instrument.
